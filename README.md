# Caoba Taller

Catálogo estático del taller. Incluye trabajos a medida, dos productos, visores 3D y una vista para probar el organizador en tu espacio.

[Ver el catálogo en GitHub Pages](https://olvidalomarge.github.io/caoba-taller/)

GitHub Pages publica desde la raíz de `main`. El sitio se sirve directamente sin compilar. Los archivos de las bibliotecas y sus licencias se encuentran en `assets/`.
